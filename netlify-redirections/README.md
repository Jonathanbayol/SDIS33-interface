# Pages de redirection Netlify

À déposer sur Netlify **après** la mise en ligne sur GitHub Pages, pour que les
anciennes adresses envoient vers les nouvelles :

- `comptoir/` → glisser-déposer sur le site sdis33pro.netlify.app
- `client/` → glisser-déposer sur le site sdis33.netlify.app

Une fois que tout le monde utilise les nouvelles adresses, les deux sites
Netlify peuvent être supprimés.
